# 发布风险接受记录（2026-07-16）

**适用版本：** `agent/security-release-gates` 合并后的管理端发布候选版本
**批准依据：** 项目负责人于 2026-07-16 明确要求将安全整改后的其他发布阻断项纳入正式风险豁免。
**批准角色：** 项目负责人（本任务授权记录）
**维护责任：** 项目负责人、前端负责人、测试负责人
**总原则：** Critical/High 依赖漏洞不得豁免；若生产审计重新出现 Critical/High，本记录自动失效并恢复“禁止发布”。

## RA-2026-001：演示环境默认管理员凭据

**状态：** 已批准（有条件、限时）
**原始级别：** P1 发布阻断
**接受范围：** 仅限隔离的本地教学/演示环境，不含公网、生产、预生产或承载真实业务数据的环境。
**风险：** 已知默认凭据可能被未授权人员使用，导致管理功能被访问。
**补偿控制：**

1. 服务只绑定受控内网或本机，不开放公网入口。
2. 演示环境不得录入真实个人信息、支付信息或生产密钥。
3. 现场演示结束后停止服务；共享环境必须限制访问人员。
4. 任何非本地部署前必须轮换管理员密码、移除界面预填并验证旧凭据失效。

**责任人角色：** 项目负责人、部署负责人
**到期：** 2026-08-15，或首次公网/生产/预生产部署前，以较早者为准。
**自动失效条件：** 网络范围扩大、接入真实数据、出现新用户、演示凭据泄露或无法证明网络隔离。
**关闭标准：** 默认密码从代码/数据初始化中移除，首次启动强制设置独立密码，并完成登录回归。

## RA-2026-002：历史前端 lint 警告

**状态：** 已批准（非阻断技术债）
**原始级别：** P2 质量风险
**当前证据：** 全量 `npm run lint -- --no-fix` 为 0 errors / 699 warnings，命令成功；语义、安全与明显逻辑错误仍保持 error 门禁。
**风险：** 大量模板格式和风格警告降低可维护性，可能掩盖后续新增警告。
**补偿控制：**

1. CI 必须持续运行全量 lint，任何 error 均阻断合并。
2. 新增/修改代码不得增加 warning 总数；安全相关规则不得降级。
3. 禁止使用自动修复一次性重排全部历史文件；按模块分批清理并配套回归。

**责任人角色：** 前端负责人
**到期：** 2026-08-15。
**自动失效条件：** warning 数超过 699、lint 出现 error、规则被进一步弱化或 CI 未执行 lint。
**关闭标准：** 历史 warning 清零或建立经批准的更低基线并持续下降。

## RA-2026-003：WebSocket 非 JSON 消息兼容

**状态：** 已批准（演示范围）
**原始级别：** P2 运行时稳定性风险
**风险：** 服务端心跳或异常文本消息可能触发解析异常，影响订单通知可靠性。
**补偿控制：** 仅在受控演示环境使用；订单状态以页面主动刷新和后端记录为准；演示人员发现通知异常时立即刷新并记录。
**责任人角色：** 前端负责人、后端负责人
**到期：** 2026-07-30。
**自动失效条件：** 用于真实订单、异常导致页面不可操作或消息丢失无法通过刷新恢复。
**关闭标准：** 明确心跳协议，解析前校验消息类型，异常消息不抛出并补充单元/联调测试。

## RA-2026-004：生产包体积与第三方 Sass 警告

**状态：** 已批准（演示范围）
**原始级别：** P2 性能/维护风险
**风险：** 主依赖包约 2.38 MiB、入口约 2.8 MiB，弱网首屏较慢；Element UI 旧 Sass 语法产生弃用警告。
**补偿控制：** 本次仅在局域网/本地演示；构建必须成功，产物大小不得较本次基线增加 10% 以上。
**责任人角色：** 前端负责人
**到期：** 2026-08-15。
**自动失效条件：** 进入公网发布、包体超过基线 10%、构建警告升级为错误。
**关闭标准：** 完成按需加载/分包与样式依赖升级，建立包体预算门禁。

## 发布决定

在以下条件同时成立时，本候选版本可按“有条件通过”发布到隔离教学/演示环境：

- 生产依赖审计保持 0 Critical / 0 High；
- 后端测试、前端单测、lint error 门禁和生产构建全部通过；
- RA-2026-001 至 RA-2026-004 未到期且补偿控制可证明执行；
- 小程序两个历史目录不包含在本次管理端发布包中，不以其任一目录作为发布源。

任何一项不满足，发布结论立即恢复为“阻断”。
